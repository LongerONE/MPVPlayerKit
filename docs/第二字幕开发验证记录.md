# 第二字幕开发与验证记录

日期：2026-10-16。范围以[实施计划](第二字幕需求与实施计划.md)为准。

## 实现范围

- 保持MPVKit 1.0.0及原锁定revision；不引入定制mpv/FFmpeg、P0补丁或格式转换。
- 新增第一/第二字幕路别、Swift与ObjC按路控制、状态和文本/ASS/时间查询、显式外挂移除及重载。
- 公共样式与字体只有一份；选轨、显隐、延迟、垂直位置、ASS覆盖策略按路控制。
- 第二路仅原生；第一路保留解码文本及文档UIKit渲染。修复内置UIKit字幕按整屏高度放大、落入控制栏的问题，改用现有视频几何映射。
- 来源占用检查、按路加载/取消/超时、迟到回调隔离、同会话来源校时及内存快照恢复。退出/换片清空来源与延迟。
- QuickPlayer提供两路控制、公共样式、简繁英自动选择、配置迁移与持久化；不持久化来源、临时显隐或延迟。
- Temby适配MPV桥接与自定义菜单，停用旧MMKV延迟链路；其他内核保持单字幕入口。烧录转独立资源有失败/超时恢复路径。
- LuWu沿用现有QuickPlayer入口，增加仅Debug启用的真实宿主回归入口和使用说明。

## 实际发现并修复的问题

1. 新增等待使用iOS16接口，已改为兼容最低版本的纳秒等待。
2. 同步字幕查询与初始化的主队列同步形成互等，实际重建/换片测试停顿。改为锁保护状态缓存、同步操作就绪守卫，并提前清除回退/停止的ready旗标。直接启动回归已完成实际补验。
3. 第一路UIKit字幕按播放器整屏高度放大并贴底，改按实际视频区域缩放定位，复拍确认修复。
4. 会话恢复的外挂隐藏/校时、第一文档路由、迟到成功清理、完整ASS策略恢复与重载缓存一致性已补齐。
